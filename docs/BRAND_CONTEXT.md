# ODDLYS 브랜드 기준 — 웹 작업용 요약

작성 2026-09-18 · 출처: ODDLYS 온라인 샵 마스터 프롬프트 v1.0 (사용자 첨부, 채팅 본문). BRAND_STATE.md v0.74·로고 검토 덱·라이브 벤치마크 PDF는 이 저장소에 첨부되지 않았다. 이 문서는 마스터 프롬프트에 정리된 기준만 옮긴다.

## 표기
- 사이트 작업 표기: **ODDLYS / 오들리즈**. 과거 작업명 ODDLY는 쓰지 않는다.
- 상표·도메인·계정 확보 여부는 확인되지 않았다. 확보된 것으로 표시하지 않는다.

## 사실 (마스터 프롬프트가 확정으로 준 것)
- 한국에서 시작하는 취미·취향 브랜드. 초기 판매: 포켓몬 / 원피스 / 리프트바운드 카드 팩·박스, 슬리브·바인더·덱박스·탑로더 등 카드 용품.
- 기본 모델: ODDLYS가 판매하는 상품을 고객이 구매. C2C·입점형 마켓플레이스 없음.
- 소개: "좋아하는 것에 푹 빠진 사람들이 모여, 각자의 취향을 이야기하고 함께 즐기는 브랜드."
- Purpose / Vision / Mission / Positioning: 마스터 프롬프트 03장 원문 그대로 (`src/pages/Misc.tsx` AboutPage에 반영).
- 사람으로 비유: 디테일을 많이 알고 신나게 설명하지만 상대를 시험하지 않는 친구. '사회화된 인싸 geek'.
- 하지 않는 것: 판매 압박, 과도한 희소성 연출, 손익 보장, 카지노처럼 보이는 표현.
- 메인 채널 라이브 판매는 복수 진행자·시간대별 프로그램. 사이트는 자체 송출·채팅 서버를 만들지 않는다. 라이브 판매 시작일·홈페이지 오픈일은 미확정.

## 시각 정체성 — 유지 / 미정
| 구분 | 기준 |
|---|---|
| 캐릭터 역할 | 오들리는 대표 얼굴. 접점마다 비중 조절. '보조로만'이라는 과거 제한은 현재 기준 아님 |
| 캐릭터 형태 | 낮고 도톰한 연속 슬라임 몸, 팔다리 없음, 두 가닥 머리, 이빨 없음, 매트한 파란 몸 |
| 표정·행동 | 호기심, 좋아하는 것 앞에서 풀리는 얼굴, 설명, 경청, 가벼운 장난 |
| 미정 | 몸 비례·머리 크기·두 가닥 차이·눈과 입·블루 HEX·최종 로고 조합 |
| 글자·그래픽 | 굵고 간결한 면, 약간의 비대칭, 컷페이퍼 같은 장난기. 정보용 글자는 또렷하고 안정적 |
| 바탕 색 제안 | 오프화이트·오프블랙 중심 + 블루 (웹 적용 제안, 최종 규정 아님) |
| 본문 폰트 제안 | Pretendard 우선 검토 (공식 서체 확정 아님) |

## 임시 웹 토큰 (프로토타입, 확정 아님)
paper `#F6F5F1` · ink `#202124` · surface `#FFFFFF` · brand-blue `#397CF5` (캐릭터·큰 면) · interactive-blue `#2457C5` (버튼·링크, 흰 글자 대비 6.47:1) · muted `#6B6A66` (paper 대비 4.96:1). 정의: `src/styles/base.css`. 브랜드 몸색과 UI 접근성 색을 억지로 같게 만들지 않는다.

## 캐릭터 사용 규칙 (사이트)
- 홈·소개·콘텐츠 진입에서 기억에 남게. 카탈로그·가격표·구매 영역에서는 정보를 가리지 않는다.
- 검색 없음·품절에 등장해도 해결 행동이 먼저 보인다 (`EmptyState`).
- 현재 저장소에 캐릭터 원본이 없다. `OddlyMark`는 실루엣 수준 **자리표시자**이며 최종 오들리가 아니다 (docs/ASSETS.md).

## 사이트 중심 문장 (제안, 슬로건 대체 아님)
"좋아하는 것을 구경하고, 알아보고, 소장하는 곳."
