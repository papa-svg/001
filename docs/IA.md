# 정보 구조(IA) · 핵심 여정 · 데이터 경계

## 글로벌 메뉴
샵 / 카드 도감 / 시세(준비 중) / 이야기. 소개·고객지원은 푸터. 라이브는 이야기 하위 + 실제 방송 중일 때만 별도 진입점.
상품 카테고리(팩·박스·용품)와 게임/IP(포켓몬·원피스·리프트바운드)는 별도 축 — 필터에서 각각 선택.

## 경로 (프리뷰: `/concepts/{a|b|c}` 접두어)
| 화면 | 경로 | 상태 |
|---|---|---|
| 홈 | `/` | A/B/C 각각 구현 |
| 샵 | `/shop?category&game&language&stock&sort&q` | 공통 (표현만 방향별) |
| 상품 상세 | `/products/[slug]` | A/B/C 구성 변형 |
| 세트 목록 | `/sets` | 공통 (B는 표) |
| 세트 상세 | `/sets/[setId]?view&cq&rarity&art&type` + `#intro/#products/#hits/#cards/#more` | A/B/C 구성 변형 |
| 개별 카드 | `/cards/[printingId]` | 기본 정보 + 샘플 시세 요약 (차트·플랫폼 비교는 후속) |
| 시세 | `/market` | 준비 상태 화면 (빈 링크 공개 안 함) |
| 이야기 | `/stories`, `/stories/[slug]` | 목록 + 연결 구조 (본문은 3단계) |
| 라이브 안내 | `/live` | 편성 없음 상태 |
| 검색 | `/search?q=` | 상품/세트/카드/이야기 구분 결과 |
| 저장 목록 | `/saved` | 로컬 저장 |
| 장바구니 | `/cart` (`/checkout` → cart로 리다이렉트) | 데모, 결제 미연결 |
| 안내 | `/about`, `/help` | 정책 미확정 문구 |
| 비교 | `/`(비교 목록), `/compare`(iframe 나란히) | 프리뷰 전용 |

필터·보기 방식·카드 필터는 URL에 보존 → 공유·뒤로 가기·복원 가능 (QA로 확인).

## 핵심 여정 (마스터 프롬프트 05장)
1. 취향 콘텐츠(홈 큐레이션·이야기) → 세트 발견
2. 세트 페이지 → 전체 카드·눈여겨볼 카드 확인 (기준: 편집 추천 / 공식 레어도 / 가격 상위 구분)
3. 개별 카드 → 정확한 판본·참고 시세 확인
4. 카드 → "수록될 수 있는 세트 상품"(확정 구성 아님) 및 관련 용품
5. 구매 여부와 무관하게 저장 → 재방문

'이 카드가 수록된 세트 상품'과 '이 카드를 구매'는 다른 행동 → 카드 상세에 단품 판매 없음/랜덤 구성 안내를 분리 표시. ODDLYS 장바구니로 가는 '이 카드 구매' 버튼 없음.

## 화면 우선순위
2단계(비교): 홈 첫 화면·첫 상품 섹션 / 상품 상세 구매 영역(데스크톱·모바일 바) / 세트 상세 힛카드·전체 카드 → **완료**. 보조로 샵·검색·장바구니·카드 상세·저장·이야기·안내도 동작.
3단계(선택 후): 카드 상세 심화, 이야기 본문, 라이브 편성, 시세 UI 계약 마감, 결제 전 단계 화면.

## 데이터 경계
- Product ≠ SKU ≠ Set ≠ Card ≠ Printing ≠ Market observation (docs/DATA_MODEL.md).
- 시세 DB는 별도 프로젝트. 이 저장소에는 화면 계약(`PriceObservationView`, `DataState`)과 샘플 fixture만 있다. 수집기·DB 없음.
- 데모 숫자는 `src/data/fixtures/market.ts`에만 있고 화면에서 '샘플' 배지로 표시. 실재 카드에 붙이지 않음(세트·카드 모두 가상).

## 상태 매트릭스 구현 현황 (18장)
| 영역 | 구현된 상태 |
|---|---|
| 검색/목록 | 초기, 결과 있음, 결과 없음(회복 경로), 필터 복원, 활성 필터 칩·전체 해제 |
| 상품 | 판매중, 재고 적음, 품절(담기 비활성·세트 링크 유지), 예약(발송 안내), 옵션 미선택(안내), 수량 초과(최대치로 보정) |
| 이미지 | 자리표시자, 미제공('이미지 없음') |
| 가격 | 정상, 표본 부족, 자료 없음, 갱신 지연, 매칭 미확인, 최근 거래 없음(호가만) |
| 저장 | 저장/취소 토스트, 로컬 저장 안내 |
| 장바구니 | 비어 있음, 담김, 삭제+되돌리기, 수량 변경, 품절 라인, 재고 초과, 예약 혼합 안내, 주문 비활성(데모) |
| 콘텐츠/라이브 | 공개 콘텐츠(샘플), 라이브 없음 상태 |
| 미구현 | 로딩/오류 상태(정적 fixture라 발생하지 않음 — `ErrorState` 컴포넌트만 준비), 재고/가격 갱신 알림 |
